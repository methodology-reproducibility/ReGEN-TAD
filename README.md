# Anonymous Reproducibility Repository

This repository contains code and configuration files for reproducing the simulation studies, benchmark comparisons, sensitivity analyses, and semantic interpretation examples reported in the accompanying anonymous manuscript.

The repository has been anonymized for peer review. Author names, institutional paths, local machine paths, credentials, and identifying metadata have been removed.

## Installation

The experiments can be run using `pip`.

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt
```

## Quick Start

After installing the environment, verify that the main implementation imports and runs:

```bash
python ReGENTAD.py
```

Run a simulation script directly from the repository root:

```bash
python simulation_code/synthetic_structural_simulations_final_revised.py
```

## Reproducing Results

The main experimental scripts are organized as follows:

- `simulation_code/synthetic_structural_simulations_final_revised.py`: structural anomaly simulations.
- `simulation_code/synthetic_stocks_simulations_final_revised.py`: financially structured anomaly simulations.
- `simulation_code/main_synthetic_clean_final_revised.py`: clean in-control false positive rate experiments.
- `simulation_code/hyperparam_sensitivity_revised.py`: hyperparameter and scoring sensitivity analysis.
- `competitors/`: benchmark and baseline anomaly detection implementations.
- `ReGENTAD.py`: main ReGENTAD implementation and optional semantic interpretation support.

Generated tables, checkpoints, logs, and figures should be saved under:

```text
results/
```

## Data

No proprietary or personally identifying data are included. Synthetic data are generated by the simulation scripts. If real financial data are used, users should obtain them independently from their chosen data provider and keep them outside the anonymized repository unless redistribution is permitted.

## Optional API-Based Baselines and Interpretation

Some optional components require API access:

- TimeGPT/Nixtla baselines require `NIXTLA_API_KEY` or `TIMEGPT_API_KEY`.
- Optional Groq-based semantic interpretation requires `GROQ_API_KEY`.

Set credentials through environment variables only. Do not hardcode API keys or credentials in source files.

# Anonymous Reproducibility Repository

This repository contains code and configuration files for reproducing the simulation studies, benchmark comparisons, ablation studies, and semantic interpretation examples reported in the accompanying anonymous manuscript.

The repository has been anonymized for peer review. Author names, institutional paths, local machine paths, and identifying metadata have been removed.

## Installation

The experiments can be run using either `pip` or `conda`.

### Option 1: pip

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install --upgrade pip
pip install -r requirements.txt
```

### Option 2: conda

```bash
conda env create -f environment.yml
conda activate anonymous-anomaly-env
```

## Quick Start

After installing the environment, run one of the example notebooks:

```bash
jupyter lab notebooks/quick_start_regentad.ipynb
```

or run a simulation script directly:

```bash
python experiments/run_structural_simulations.py
```

## Reproducing Results

The main experimental results are organized as follows:

- `notebooks/structural_simulations.ipynb`: structural anomaly simulations.
- `notebooks/financial_simulations.ipynb`: financially structured anomaly simulations.
- `notebooks/clean_fpr_simulations.ipynb`: clean in-control false positive rate experiments.
- `notebooks/ablation_study.ipynb`: pipeline-level ablation study.
- `notebooks/llm_semantic_interpretation_example.ipynb`: example of post-hoc semantic interpretation using structured evidence maps.

Generated tables and figures should be saved under:

```text
results/tables/
results/figures/
```

## Data

No proprietary or personally identifying data are included. Synthetic data are generated by the simulation scripts. If real financial data are used, users should obtain them independently from their chosen data provider and place them in the appropriate local data directory.
